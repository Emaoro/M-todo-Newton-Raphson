Propuesta de automatización

Esta aplicación automatiza el método de Newton-Raphson normal, permitiendo encontrar raíces aproximadas de funciones no lineales mediante un proceso iterativo.

Método Newton-Raphson

El usuario ingresa la función, su derivada, el valor inicial, la tolerancia y el número máximo de iteraciones.

Resultado paso a paso

La aplicación muestra la tabla de iteraciones, el error, la raíz aproximada, la gráfica y el desarrollo del cálculo.

¿Qué realiza la aplicación?

Calcula automáticamente cada iteración del método Newton-Raphson usando la fórmula:

xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)

Al finalizar, la aplicación muestra si el método logró converger de acuerdo con la tolerancia ingresada.

Información del proyecto

Trabajo especial

Proyecto de Métodos Numéricos para la Ingeniería enfocado en la automatización del método de Newton-Raphson normal.

Objetivo

Automatizar el cálculo de raíces aproximadas de funciones no lineales mediante el método Newton-Raphson, mostrando procedimiento, tabla, error, resultado final y gráfica.

Modelo matemático

El método Newton-Raphson utiliza una aproximación inicial para obtener valores cada vez más cercanos a la raíz de una función.
